## Anomalies

The observed base layer outputs a physically pressed Y as `y` and a physically pressed Z as `z`.

This differs from the existing asset [`app/src/main/assets/common/layouts/qwertz.json`](../../../app/src/main/assets/common/layouts/qwertz.json), which defines `KEYCODE_Y -> z` and `KEYCODE_Z -> y`. This difference is central to this snapshot, because a QWERTZ context was observed here on a physical QWERTY keyboard.

The existing Titan 2 device SYM asset [`app/src/main/assets/devices/titan2/device_sym_key_mappings.json`](../../../app/src/main/assets/devices/titan2/device_sym_key_mappings.json) matches the observed secondary assignment of the letter keys. Alt+Space is not defined there, but was observed in the export as the private-use code point ``.

## Coverage notes

- Backspace was recorded only as a base and Ctrl event, each without Unicode output.
- Space was observed in Base, Shift and Alt; Alt+Space yields ``.
- Ctrl is documented only for the combinations listed above.
- SYM was not captured as a normalizable SYM page.
- This snapshot documents observed behavior, not the desired layout model.
