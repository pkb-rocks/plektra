# Unihertz Titan 2

This directory archives observed keyboard behavior of the Unihertz Titan 2 on real hardware.

The entries describe what was measured on a specific device with specific firmware and app version. This is not automatically the desired target behavior, and it says nothing about whether Unihertz or Android will keep this behavior in later updates.
