# Device support

This is a selection of devices tested directly or supported by the community. Technical hardware notes are kept in [device-support](device-support/).

## Directly tested

The maintainer owns these devices and uses them for development and testing.

- **Unihertz Titan 2** — built-in physical keyboard. [Technical notes](device-support/titan-2.md)
- **Unihertz Titan 2 Elite** — built-in physical keyboard and rounded-display geometry. [Technical notes](device-support/titan-2-elite.md)
- **Google Pixel 7a + Clicks Power Keyboard** — a directly tested physical keyboard combination.
- **Samsung Galaxy Z Fold6** — standalone software keyboard and folding behaviour; also used with the Clicks Power Keyboard. Further improvements for foldables are planned.

## Upcoming

- **[Clicks Communicator](https://www.clicksphone.com/communicator)** — Plektra support planned. The website shows a composed Plektra preview using the manufacturer's device render and a Titan 2 Elite capture.
